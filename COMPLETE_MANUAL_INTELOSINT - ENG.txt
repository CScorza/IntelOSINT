OPERATIONAL MANUAL - IntelOSINT.2
Version: CSCORZA IntelOSINT V.2
Date: 04/13/2026

This manual is designed for daily users of the tool.
Purpose: To quickly understand what you can query, what output you receive, and how to export the results for reports and follow-ups.

1) Quick Overview
IntelOSINT.1 is a local search tool (Python + web interface) featuring 6 areas:

Social

WEB Dork

Phone

GDrive Doc

Financial

Domain

Everything is handled through the browser. The operator enters a target as input, chooses the relevant tab, reads the results, and decides whether to save them to the report.

2) Access and Startup
When starting the app:

Open the local page (the address is shown in the console).

Log in if necessary.

In the settings, enter any useful credentials (if available): Instagram / TikTok sessions (for social analysis), Telegram APIs (id + hash + phone), and extra keys (Shodan, NumVerify, DNS history, etc.) only if you have them.

Practical Note:
The more credentials you provide, the more comprehensive your results will be. If you do not have credentials, some features will still operate in a basic mode.

3) How to Read the Results
For each search, you will receive "cards" displaying:

Type of source (Social, Messaging, Domain, etc.)

Status (Found / Not found)

Main extracted data

Action buttons (open link, investigate further, export, etc.)

Simple Color Rule:

Green: Strongest signal.

Yellow/Red: Requires verification or indicates an incomplete result.

Standard Buttons:

OPEN LINK: Opens the found page.

ADD TO REPORT: Saves the data in the final summary.

Dedicated Exports: CSV, PDF, or ZIP (when available).

4) Social Tab
When to use it:

You want to see if a username or name appears across multiple social networks.

You need to check an email on platforms with public accounts.

Useful Inputs:

Username (@name / username)

Email

Person's name

Typical Outputs:

List of platforms with positive matches.

Profile name, bio, account status, and follower count (when available).

Direct profile link.

Available Actions:

Open the profile directly.

Add relevant results to the report.

Use the profile scraper to download content, when supported by the platform.

Profile Scraper (UI):

Instagram: Click the DOWNLOAD CONTENT button on the found social card.

Telegram: Click the DOWNLOAD CONTENT button on the found social card.

TikTok: Click the DOWNLOAD CONTENT button on the found social card.

Scrape Format:

Option Selection: Data only, media only, links only, followers/following, or full download.

Final Result: A ZIP file containing JSON/CSV files, images/media, and an integrity hash (MD5/SHA256).

Operational Tip:
When investigating a person, try a simple search in the Social tab first, then deeply investigate only the channels showing strong signals.

5) WEB Dork Tab
When to use it:

To find public traces on the web, blogs, forums, or copies of materials.

To begin a rapid online footprint reconnaissance.

Query Types:

Simple keywords: Name + Surname + City.

Breach checks: Email + "breach" (use with caution).

Basic dorks: intitle:, site:, inurl:.

Typical Output:

List of results including title, snippet, and URL.

Unique results with duplicates removed.

Operational Tip:
Start with 5-10 short queries, then save only the truly relevant ones.

6) Phone (Messaging) Tab
When to use it:

To validate a phone number and understand its characteristics.

Input:

International format is recommended (e.g., +39...).

Output:

Number format (international + local).

Estimated country/area, timezone, and line type.

Normalized carrier/operator (when available).

Contact reliability score (0-100).

Quick Telegram verification.

Quick links to WhatsApp and Telegram.

Card Actions:

OPEN TELEGRAM

OPEN WHATSAPP

Operational Tip:
Always note that numbers should only be used for lawful and authorized verifications, avoiding any form of abuse.

7) GDrive Doc Tab
When to use it:

To quickly verify a Google Drive document or folder via a link or ID.

Input:

Full Google Drive link (view/open/folder).

Direct ID.

Output:

Resource type (file/folder).

Visibility/publication status.

Size (when available).

Owner / domain (when available).

Access status and permissions (capabilities).

Operational Tip:
Ensure you copy the correct ID (it can be extracted from various URL formats). If one method fails, try link variations like /view, /open?id=, or uc?export.

8) Financial Tab
When to use it:

For quick verification of crypto targets or wallets.

For basic checks on Revolut or PayPal profiles (when available).

Input:

Wallet addresses (BTC, ETH, SOL, etc.).

Revolut alias or PayPal link.

Wallet Output:

Balance and transaction summary.

First/last transaction dates (when available).

Main counterparties.

Simplified risk level (exchange, mixer, bridge, etc.).

Token metadata (if present).

Payment Output:

Verification of whether the associated profile is reachable.

Operational Tip:
Use wallet data as indicators, not as definitive proof.

9) Domain Tab
When to use it:

For reconnaissance on a domain or website.

All-in-One Output:

Registration data (WHOIS / RDAP).

DNS records (A, AAAA, MX, NS, TXT, CAA).

Security headers and basic security checks.

Robots.txt and sitemap.

HTTPS certificate and chain.

Certificate transparency.

Web history / cache.

Technical mapping and linked IPs.

Potential IP scans and reverse DNS (when useful).

Operational Tip:
Start with WHOIS and RDAP, then check the certificate and headers. This is useful for distinguishing between legitimate, abandoned, or compromised domains.

10) Telegram (Global Functions)
The tool also includes Telegram support features:

Code sending and verification (when API session is configured).

Channel/group monitoring.

Downloading monitor logs and participant CSVs.

Exporting Telegram reports to PDF.

In Practice:
From a Telegram result, you can initiate monitoring. Once the selected period ends, you can export the evidence.

11) Exports
You have access to:

Full PDF report from the main panel.

Telegram participants CSV (for channels/groups).

Scraping ZIP files for advanced collection results (supported by the Instagram, Telegram, and TikTok scrape cards).

How to Use the Report:

Open the relevant results.

Click ADD TO REPORT where necessary.

Use the final PDF export feature.

Archive the file using the target's name and the date.

Technical Operational Note:
If a full sweep on YouTube or GitHub is required, these scrapers are currently available on the backend and can be triggered by extending API usage (/api/scrape/start), but they do not have a direct button in the basic UI flow yet.

13) Limits and Best Practices
Some sites change their structure frequently and may block requests.

Some data might not be public; an empty result is not necessarily an error.

Always cross-reference multiple sources before drawing operational conclusions.

Respect legal and privacy limits: the tool supports open-source investigation, not hacking or unauthorized access.

14) Recommended Mini Operational Flow (5 minutes)
Enter the target in the Social or WEB Dork tab, depending on the case.

Save the most interesting matches to the report.

Complete the profile using the Phone, Domain, and Financial tabs if confirmation is needed.

Check the GDrive Doc tab for potential document exposure.

Export the PDF / CSV / ZIP and attach it to the operational dossier.
